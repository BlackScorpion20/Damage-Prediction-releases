# Damage Prediction – Releases

Fertige Versionen von **Damage Prediction** für World of Warcraft: Forever (Interface 16001).
Zeigt auf der Ziel-Lebensleiste von EllesmereUI, wie viel dein Zauber, dein Finisher und deine
nächsten Zauber abziehen.

**Installieren:** die Zip der neuesten Version unter *Releases* laden und nach
`_forever_/Interface/AddOns` entpacken, oder in der App „WoW Addons“ diesen Link als Quelle eintragen.

Benötigt **EllesmereUI**.
